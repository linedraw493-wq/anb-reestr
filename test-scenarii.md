# Что тестить — истории пользователя

Живой сайт: **https://anb-reestr.vercel.app**. Тестировать **с телефона** —
мобильная вёрстка это приоритет спеки.

**Что проверено мной 06.09.2026 на бою** — всё, что открыто без входа:
раздел E (каталог, отбор, сортировки, страницы, карта, ссылка с фильтрами,
страница блогера, счётчик просмотров) и раздел F (телефон наружу не уходит,
файлы диска не отдаются, админка гостю закрыта, чужой скрин не достать,

**Что осталось владельцу:** всё, что за входом — разделы A, B, C, D, H и
мобильный G. Пароли и коды агент не набирает, это правило дома.

- **вход блогера:** код уходит настоящей SMS через Mobizon. На номерах

- **вход администратора:** `/vhod` → «Вход для администратора»,

## A. Петля участника — ядро спеки

Тот самый «один сценарий, один телефон» из приёмки. Пройти целиком, с телефона.

**Машиной этот круг уже пройден** — `app/api/tests/test_polnyy_krug.py`:
админ входит по `admin`/`admin`, заводит человека по номеру, получает
ссылку; «в другом браузере» человек по ней входит кодом, заполняет карточку,
грузит скрин, попадает в каталог, ссылка после этого гаснет, телефон наружу
не уходит. Проверка живёт в прогоне и развалится, если что-то сломают.

Руками всё равно проходить: машина не увидит, что кнопка мелкая, что SMS не
пришла и что с телефона форма уезжает за край.

- [ ] **A1. Новый блогер по ссылке.** Админ в «Приглашениях» жмёт «Ссылка для
      нового блогера», вводит ник, копирует ссылку `/i/…`. Открыть её на
      телефоне → экран «Это вы?» с этим ником.
- [ ] **A2. Ввод номера.** Вписать свой номер, поставить галочку согласия →
      «Получить код» → экран ввода кода.
- [ ] **A3. Код.** Ввести код из Telegram → пускает, ведёт на «Заполните
      карточку». (На стенде подойдёт `111111`.)
- [ ] **A4. Заполнение карточки.** Ник, ссылка на профиль, подписчики, охват,
      тематика, город (и район, где есть), язык, ставка. Виден живой
      предпросмотр.
- [ ] **A5. Скрин статистики.** Загрузить настоящий скрин статистики с
      телефона → приняло, показывает, **цифры подставились моделью**. Не
      прочиталось — вписать руками, карточка честно «со слов».
- [ ] **A6. Публикация.** Сохранить → карточка уходит в каталог (модерация
      сейчас выключена).
- [ ] **A7. Карточка в каталоге.** Открыть каталог → найти свой ник поиском →
      карточка на месте, охваты видны и помечены «со слов». Телефона нет.
- [ ] **A8. Ссылка сгорела.** Открыть ту же `/i/…` ещё раз → «ссылка
      недействительна».
