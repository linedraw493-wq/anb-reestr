# Что тестить — истории пользователя

Живой сайт: **https://anb-reestr.vercel.app**. Тестировать **с телефона** —
мобильная вёрстка это приоритет спеки.

Что уже проверено мной: полный круг участника на стенде и на бою на уровне
API (вход `admin`/`admin` даёт `ok`, сайт отвечает, каталог отдаётся).
**Не проверено руками: боевой UI с телефона** — вот его и надо пройти.

## Демо-доступ

Снимается перед боевым запуском (см. раздел I).

- код на входе по номеру — **`111111`**, подходит любому номеру, что есть
  в базе, и в приглашении тоже;
- вход администратора — логин **`admin`**, пароль **`admin`**
  (`/vhod` → «Вход для администратора`);
- телефон-админ владельца: **+7 705 281 93 42**.

Отметка: `[ ]` не проверено · `[x]` работает · `[!]` сломано (записать, что).

## A. Петля участника — ядро спеки

Тот самый «один сценарий, один телефон» из приёмки. Пройти целиком, с телефона.

- [ ] **A1. Новый блогер по ссылке.** Админ в «Приглашениях» жмёт «Ссылка для
      нового блогера», вводит ник, копирует ссылку `/i/…`. Открыть её на
      телефоне → экран «Это вы?» с этим ником.
- [ ] **A2. Ввод номера.** Вписать свой номер, поставить галочку согласия →
      «Получить код» → экран ввода кода.
- [ ] **A3. Код.** Ввести `111111` → пускает, ведёт на «Заполните карточку».
- [ ] **A4. Заполнение карточки.** Ник, ссылка на профиль, подписчики, охват,
      тематика, город (и район, где есть), язык, ставка. Виден живой
      предпросмотр.
- [ ] **A5. Скрин статистики.** Загрузить картинку с телефона → приняло,
      показывает. Цифры остаются введённые руками (ИИ-чтение отключено — так
      задумано).
- [ ] **A6. Публикация.** Сохранить → карточка уходит в каталог (модерация
      сейчас выключена).
- [ ] **A7. Карточка в каталоге.** Открыть каталог → найти свой ник поиском →
      карточка на месте, охваты видны и помечены «со слов». Телефона нет.
- [ ] **A8. Ссылка сгорела.** Открыть ту же `/i/…` ещё раз → «ссылка
      недействительна».

## B. Вход

- [ ] **B1. Повторный вход по номеру.** `/vhod` → номер регистрации → код
      `111111` → пускает. Карточка заполнена — ведёт в каталог, а не на
      «заполните».
- [ ] **B2. Неизвестный номер.** Номер, которого нет в базе → «такого номера в
      реестре нет», код не отправляется.
- [ ] **B3. Неверный код.** `222222` → «неверный код», счётчик попыток вниз.
- [ ] **B4. Вход администратора по паролю.** `/vhod` → «Вход для
      администратора» → `admin` / `admin` → в админке.
- [ ] **B5. Неверный пароль.** `admin` / что угодно другое → «логин или пароль
      не подходят».
- [ ] **B6. Разные формы номера.** Один номер как `+7 705…`, `8705…`, `7705…`,
      со скобками и пробелами → все ведут в один кабинет.
- [ ] **B7. Выход.** «Выйти» → сессия сброшена, снова гость.

## C. Кабинет блогера

- [ ] **C1. Правка сразу.** Поменять ник, ссылки, тематику, язык, ставку →
      сохранить → в каталоге изменилось сразу.
- [ ] **C2. Правка после публикации.** Опубликованный блогер меняет карточку →
      экран не говорит «напишите администратору», правка проходит.
- [ ] **C3. Причина возврата.** Если модератор вернул карточку с причиной —
      блогер видит причину на своём экране.
- [ ] **C4. Готовность.** Пустой обязательный пункт → показывает «готово N из M».

## D. Админка

Войти как `admin` / `admin`.

- [ ] **D1. Меню «Админка».** Видны: Проверка карточек, Приглашения, Списки,
      Сводка.
- [ ] **D2. Приглашения — список.** Вкладки (не открывали / открыли /
      зарегистрировались / просроченные), поиск по нику, счётчики.
- [ ] **D3. Ссылка существующему.** «Выпустить» / «новая ссылка» у блогера из
      таблицы → ссылка появляется, копируется.
- [ ] **D4. Ссылка новому блогеру.** Кнопка «Ссылка для нового блогера` → ник →
      ссылка + «скопировать».
- [ ] **D5. Резервный код.** «Резервный код» у блогера → код показан на экране,
      в Telegram не ушёл, живёт 5 минут. Блогер входит этим кодом.
- [ ] **D6. Выгрузка таблицей.** CSV скачивается, кириллица не кракозябрами,
      колонки: ник, телефон, состояние, ссылка, годна до.
- [ ] **D7. Проверка карточек.** Очередь по вкладкам (черновик / на проверке /
      в каталоге / отклонена), страницами.
- [ ] **D8. Правка карточки модератором.** Открыть → поменять поля → сохранить.
- [ ] **D9. Пометка достоверности.** «со скрина — проверено» / вернуть на «со
      слов» → в каталоге видно.
- [ ] **D10. Скрыть / вернуть.** Скрыть → ушла из каталога, данные целы.
      Вернуть → снова в каталоге.
- [ ] **D11. Одобрить / отклонить.** Только при включённой модерации (сейчас
      выключена, см. I4). Отклонить с причиной → блогер видит причину.
- [ ] **D12. Завести карточку руками.** По номеру телефона → карточка +
      приглашение.
- [ ] **D13. Удаление человека.** Есть только у админа. У модератора — «скрыть».
- [ ] **D14. Списки.** Тематики / города / районы: добавить, переименовать,
      скрыть, слить два в один. У каждого пункта — число карточек.
- [ ] **D15. Сводка.** Воронка: разослано → открыли → подтвердили номер →
      заполнили → в каталоге. Числа осмысленные.
- [ ] **D16. Модератор ≠ админ.** Завести кого-то модератором → у него нет
      «Списки», «Сводка», «Удалить».

## E. Публичный каталог (без входа)

- [ ] **E1. Главная — это каталог.** `/` → сразу список карточек, не рассказ
      про реестр.
- [ ] **E2. Поиск по нику.**
- [ ] **E3. Фильтры.** Подписчики от/до, охват от, тематика, город, район,
      язык, цена до — каждый сужает выдачу.
- [ ] **E4. Сортировки.** По охвату, по подписчикам, дешевле, новые.
- [ ] **E5. Страницы.** Листание вперёд/назад, номер страницы держится.
- [ ] **E6. Карта Казахстана.** Точки по городам, число в точке = число
      карточек в этом городе по текущему фильтру.
- [ ] **E7. Ссылка с фильтрами.** Скопировать адрес с выставленными фильтрами,
      открыть в новой вкладке → те же фильтры.
- [ ] **E8. Страница блогера.** Клик по карточке → `/b/…` → профиль, ссылки,
      охваты, фото. Телефона нет. Счётчик просмотров растёт.
- [ ] **E9. Отбор не тормозит.** Быстро набрать «100000» в поле «от» → выдача
      обновляется после паузы, не дёргается на каждую цифру.

## F. Приватность и безопасность

- [ ] **F1. Телефон нигде наружу.** Ни в каталоге, ни на странице блогера, ни
      в ответе `/api/katalog`.
- [ ] **F2. Чужой скрин не достать.** Гостем или другим блогером открыть
      `/api/kartinki/<номер>` перебором → чужой скрин статистики не отдаётся
      (только своё фото карточки из каталога).
- [ ] **F3. Файлы диска не отдаются.** Адрес вида `/../../.env` → ничего.
- [ ] **F4. Админка закрыта гостю.** `/moderator` без входа → «сюда нельзя».
- [ ] **F5. Счёт попыток.** Больше 10 попыток входа с устройства за минуту →
      «слишком часто».
- [ ] **F6. Согласие записано.** После входа в базе `soglasiya` — новая строка
      с версией.
- [ ] **F7. Поисковики (только бой).** В заголовках ответа есть
      `X-Robots-Tag: noindex`.

## G. Мобильный — приоритет спеки

- [ ] **G1.** Экраны входа читаются на телефоне, ничего не уезжает за край.
- [ ] **G2.** Каталог и фильтры: фильтры за кнопкой, карточки в один столбец.
- [ ] **G3.** Форма карточки: поля, предпросмотр, загрузка фото и скрина с
      камеры/галереи.
- [ ] **G4.** Админка: список приглашений, кнопки «скопировать» и «новая
      ссылка» нажимаются.
- [ ] **G5.** Ввод кода: клавиатура цифровая, вставка кода из буфера работает.

## H. Границы и ошибки

- [ ] **H1. Просроченная ссылка.** Приглашение старше 30 дней →
      «недействительна».
- [ ] **H2. Использованная ссылка.** Уже прошли по ней → «недействительна».
- [ ] **H3. Занятый номер.** В приглашении вписать номер, уже привязанный к
      другой карточке → «этот номер уже привязан», предлагает войти по номеру.
- [ ] **H4. Заготовка без номера.** Открыть приглашение блогера из таблицы без
      телефона → просит вписать номер сразу.
- [ ] **H5. Битый скрин.** Загрузить не-картинку или крошечный файл-ловушку →
      «не картинка», сервер не падает.
- [ ] **H6. Обновление на вводе кода.** В приватном окне обновить `/kod` →
      отправляет на `/vhod`, не падает.
- [ ] **H7. Двойной ввод номера.** Ввести номер, стереть, ввести снова разными
      способами → не копится «+7 77777…».

## I. Демо-режим — проверить, что снимается перед боем

- [ ] **I1.** `MASTER_KOD` пуст → код `111111` больше не подходит, работает
      только настоящий (из Telegram / резервный).
- [ ] **I2.** `ADMIN_LOGIN`/`ADMIN_PAROL` пусты → «Вход для администратора»
      пропадает / отвечает «выключено».
- [ ] **I3.** `ADMIN_TELEFONY` с номером клиента → клиент входит по своему
      номеру, а не только по `admin`/`admin`.
- [ ] **I4.** `MODERATSIYA=1` → новая карточка не идёт в каталог сразу, встаёт
      в очередь модератора; правка цифр у опубликованной — тоже.
- [ ] **I5.** Ключ Anthropic вставлен → скрин читается моделью, цифры
      подставляются с пометкой «со скрина».
