## Что делаем

Сайт-реестр на ~277 реальных блогеров: блогер заходит по персональной
ссылке-приглашению, подтверждает телефон кодом, заполняет карточку и грузит
скрин статистики (модель читает со скрина охваты/подписчиков); заказчик
получает публичный каталог с поиском и фильтрами для подбора блогеров под
рекламу; администратор ведёт базу без программиста. Срок — 5 рабочих дней,
100 000 ₸ за этап.

**Сейчас — билд, шаг 1 из трёх сделан.** Решения 01–02.09.2026 приняты, код
пошёл. Порядок сборки цепочки входа: **1) экраны на заглушке — сделано ·
2) сервер и база · 3) подключить Twilio Verify.**

Стек взят у «Лидера», не изобретался: Vite + React 19 + TypeScript на
экранах, FastAPI + asyncpg + PostgreSQL на сервере. **Одна служба** — на
бою FastAPI сам отдаёт собранные страницы. Вход держится cookie,
недоступной скриптам.

**Живой стенд:** `https://anb-reestr.vercel.app` (плюс `/kartochka`,
`/moderator`). Vercel, проект `dan-si/anb-reestr`, аккаунт владельца,
`noindex`. Обновляется руками из `app/web`:
`npx vercel build --prod --yes && npx vercel deploy --prod --prebuilt --yes`.

**Коды входа настоящие** — через Telegram-бота `@Kikokpklkbot`, временно
вместо SMS-оператора: все коды падают в один чат владельца. Всё остальное
(приглашения, карточки, заявки) пока живёт в браузере — для них нужна
база, она появится на Railway. Подробности — `app/README.md`.

**Окно регистрации карточки собрано** — вариант А: форма слева, живой
предпросмотр справа; на телефоне карточка наверх, внизу полоса «готово N
из 7». Публикация только после проверки модератором. Списки тематик,
городов и районов **временные**, лежат одним файлом
`app/web/src/lib/spravochniki.ts`. Чтение скрина моделью — поддельное,
настоящее ещё не делалось ни разу и собирается отдельно.

**Дальше:** сервер и база (шаг 2), модераторская очередь в админке,
каталог с фильтрами, настоящее чтение скрина.
