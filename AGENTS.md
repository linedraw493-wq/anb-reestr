## Что делаем

Сайт-реестр на ~277 реальных блогеров: блогер заходит по персональной
ссылке-приглашению, подтверждает телефон кодом, заполняет карточку и грузит
скрин статистики (модель читает со скрина охваты/подписчиков); заказчик
получает публичный каталог с поиском и фильтрами для подбора блогеров под
рекламу; администратор ведёт базу без программиста. Срок — 5 рабочих дней,
100 000 ₸ за этап.

**Сейчас — билд, шаг 1 из трёх сделан.** Решения 01–02.09.2026 приняты, код
пошёл. Порядок сборки цепочки входа: **1) экраны на заглушке — сделано ·
2) сервер и база · 3) подключить Twilio Verify.**

Стек взят у «Лидера», не изобретался: Vite + React 19 + TypeScript на
экранах, FastAPI + asyncpg + PostgreSQL на сервере. **Одна служба** — на
бою FastAPI сам отдаёт собранные страницы. Вход держится cookie,
недоступной скриптам.

## Границы

- Персональные данные 277+ живых людей — телефоны, номера, переписка.
  Выгрузки с людьми в git не едут никогда, ни в приватный репозиторий, ни
  «на минуту».
- Ничего не деплоится и не пушится наружу без слова владельца — это
  необратимое.
- Решение по SMS (раунд 4 в `voprosy-i-dyry.md`): готовый OTP-сервис через
  API. Тест на нашем Twilio Verify, продакшн — аккаунт и оплата заказчика.
- Всё подменяемое — за выключателем в настройке, не в коде экранов:
  `VITE_API=fake|live`, на сервере `OTP=fake|twilio`. Смена провайдера это
  замена ключей, а не переписывание.
- Стиль вынесен в переменные в начале `app/web/src/styles.css`. Пришлёт
  заказчик свой дизайн — переодеваем правкой этого блока.
